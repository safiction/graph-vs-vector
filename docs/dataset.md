## Dataset source
Link to the github repo: https://github.com/onyx-dot-app/EnterpriseRAG-Bench

Link to the original paper: https://doi.org/10.48550/arXiv.2605.05253

Download the dataset from the latest release or HuggingFace:

all_documents.zip — all documents in a single archive.
<source_type>_slice_<slice_number>.zip — individual zip files, each containing up to 5000 docs (no nested directory structure).
The question set can be found in questions.jsonl and also under the releases.

Usage explained in the file quickstart.md: Evaluate your system — download the dataset, run your RAG pipeline, and score the results.

How download the data, written scripts: src/scripts
